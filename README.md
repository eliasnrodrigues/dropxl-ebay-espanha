# Catálogo dropXL · eBay Espanha

Página independente para preparar anúncios manuais em espanhol com base em produtos candidatos da dropXL.

## Acessar

[Abrir o catálogo publicado](https://eliasnrodrigues.github.io/dropxl-ebay-espanha/)

## Como usar

- Pesquise cada item no catálogo da sua conta dropXL e confirme SKU, variação, preço, estoque, origem do envio e prazo.
- Compare anúncios e vendas no eBay Espanha antes de definir preço e margem.
- Copie e adapte os rascunhos em espanhol; os textos não são anúncios ativos.
- Os produtos foram selecionados de uma lista sazonal da dropXL e não são garantia de vendas.

## Publicação

O GitHub Actions publica o conteúdo da branch `main` no GitHub Pages.


## Integração experimental

O diretório `dropxl-ebay-europa/` contém uma proposta de worker para integração, ainda dependente de configuração e validação com contas e credenciais reais. Consulte o [README da integração](dropxl-ebay-europa/README.md). A página do catálogo serve apenas para pesquisa e preparação manual de anúncios.
